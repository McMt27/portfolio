SAÉ 2.01
Active Directory

Intégration d'une station à un domaine, gestion des GPO et automatisation PowerShell.

01. Résumé du Projet

Cette SAE visait à mettre en œuvre une infrastructure de domaine Active Directory dans un environnement virtualisé sous Proxmox. Nous avons créé une machine virtuelle Windows Server 2019, promue en contrôleur de domaine, et une machine Windows 10 intégrée à ce domaine. Le projet, individuel, avait pour objectif de maîtriser les bases de l'administration ADDS, de la gestion des GPO, des profils itinérants, ainsi que l'automatisation par PowerShell. En parallèle, nous avons suivi le module 2 de Cisco.

03. Actions Réalisées

  • Création VM Windows Server 2019 (Pilotes Virtio / Proxmox).
  • Promotion en Contrôleur de Domaine (ADDS + DNS).
  • Structure AD : Utilisateurs, Groupes, OU (Arborescence).
  • Intégration d'une station Windows 10 au domaine.
  • Déploiement GPO (Restrictions, Masquage paramètres).
  • Partage réseau sécurisé (ADGLP) & Profils itinérants.
  • Automatisation PowerShell (Création de comptes en masse).

🔧 Diagnostic & Résolutions

PROBLÈME RENCONTRÉ SOLUTION APPLIQUÉE
Difficulté à intégrer la VM Windows 10 au domaine. Vérification DNS et configuration manuelle de l’adresse IP du serveur DNS.
Erreur de script PowerShell sur les OU. Ajout de vérification d'existence avant création automatique ("If Exists...").

🎯 Axes d'Amélioration (V2.0)

PROBLÈMES NON RÉSOLUS PLAN D'ACTION FUTUR
Problème de consigne GPO. Tester les GPO dans tous les cas pratiques et vérifier l'application (gpresult).
PROTOCOLE CONSEILLÉ POUR OPTIMISATION
  • 01. Lire toute la documentation Active Directory avant de commencer.
  • 02. Créer les utilisateurs et OU via PowerShell dès le départ pour gagner du temps.
  • 03. Penser à tester la résolution DNS (nslookup) avant l’intégration au domaine.
  • 04. Faire un backup Proxmox (Snapshot) avant chaque étape critique.
